# ProgramStore

## 概述

`ProgramStore` 只保存行号到原始源码的映射，不长期保存语法树。使用有序映射可保证导出和 LIST 均按行号升序进行。

## 数据成员

| 名称 | 类型 | 作用 |
| :-: | :-: | :-: |
| `lines_` | `std::map<std::int32_t, std::string>` | 程序行号到原始源码的有序映射 |

## 公有成员函数

| 名称 | 作用 |
| :-: | :-: |
| `upsert` | 新增程序行，或覆盖相同行号的源码 |
| `erase` | 删除指定行号；行号不存在时不产生错误 |
| `contains` | 判断指定行号是否存在 |
| `ordered_lines` | 按行号升序返回 `SourceLine` 列表 |
| `list` | 将全部程序行按“行号 空格 源码”的格式输出 |
| `clear` | 删除全部程序行 |
