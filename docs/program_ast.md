# ProgramAst

## 概述

`ProgramAst` 表示一次完整程序解析得到的抽象语法树，独占根语句块。该类不可复制但可以移动，析构时会递归释放全部语句、条件和表达式。

## 数据成员

| 名称 | 类型 | 作用 |
| :-: | :-: | :-: |
| `root_` | `BlockStatement*` | 拥有的根语句块；移动后可以为空指针 |

## 公有成员函数

| 名称 | 作用 |
| :-: | :-: |
| `ProgramAst` | 取得根语句块的所有权 |
| `~ProgramAst` | 释放根语句块及其拥有的全部子节点 |
| 移动构造与移动赋值 | 转移根语句块所有权，并将源对象的根指针置空 |
| `root` | 返回根语句块的只读引用；对象没有根节点时产生逻辑错误 |
| `execute` | 从根语句块开始执行，并返回执行信号 |
